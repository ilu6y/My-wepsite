# موقع محمد فؤاد | معرض الأعمال الشخصي (Portfolio)

موقع تعريفي ومعرض أعمال تفاعلي للمصمم الجرافيكي **محمد فؤاد**، مصمم بهيكل برمجي حديث وسريع، يدعم الوضع الليلي (Dark Mode) وعارض صور تفاعلي (Lightbox).

---

## 📁 هيكلية وترتيب الملفات (Project Structure)

```text
My-wepsite/
├── index.html                  # الصفحة الرئيسية للموقع
├── README.md                   # توثيق المشروع
└── assets/                     # مجلد الموارد والأصول
    ├── css/
    │   └── style.css           # ملف التنسيقات والتصميم
    ├── js/
    │   └── script.js           # التفاعلات، المعرض، والوضع الليلي
    ├── fonts/                  # خطوط الموقع
    │   ├── Zain-Variable.ttf           # خط زين للنصوص العربية
    │   ├── MonumentExtended-Regular.otf   # خط Monument Extended للإنجليزي
    │   └── MonumentExtended-Ultrabold.otf # خط Monument Extended العريض
    ├── images/                 # الصور العامة
    │   └── avatar.png          # الصورة الشخصية والشعار
    └── work/                   # صور معرض الأعمال (43 عمل)
        ├── 1.png
        ├── 2.png
        └── ... (حتى 43.png)
```

---

## ✨ المميزات الرئيسية

- **الخطوط المخصصة:**
  - **خط زين (Zain):** مطبق بالكامل على النصوص والكلمات العربية.
  - **خط Monument Extended & Outfit:** مطبق على النصوص، الأرقام، والعناوين الإنجليزية.
- **معرض أعمال تفاعلي (Interactive Masonry Gallery):** عرض ديناميكي لـ 43 عملاً إبداعياً مع إمكانية التكبير والتصفح بسلاسة (Lightbox Modal).
- **الوضع الليلي والنهاري (Dark/Light Mode):** تبديل الأنماط وحفظ التفضيل في المتصفح.
- **تصميم متجاوب بالكامل (Fully Responsive):** متوافق مع كافة أحجام الشاشات والأجهزة الذكية.
